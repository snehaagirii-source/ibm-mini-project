LocalFix — A full-stack local service booking platform built with Flask and MongoDB, featuring a premium neon UI, service provider discovery, 
bookings, user authentication, and an admin dashboard.

A Flask + MongoDB local service booking platform with a premium neon UI and admin dashboard.

Users can discover local service providers such as electricians, plumbers, mechanics, tutors, cleaners, and computer 
repair professionals, view their profiles, and book services through a simple interface.

Key Features:
🔐 User registration & login
🧰 Service provider browsing
🔍 Search and category filtering
⭐ Provider ratings
📋 Provider profiles
📅 Service booking
🧾 Booking history
👨‍💼 Admin login & dashboard
🗄️ MongoDB database
🎨 Premium neon UI
📱 Responsive design
⚡ Flask backend

Tech Stack:
Frontend  → HTML, CSS, JavaScript
Backend   → Python, Flask
Database  → MongoDB
UI        → Custom Neon CSS
